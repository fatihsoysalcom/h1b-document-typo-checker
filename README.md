# H1B Document Typo Checker

This example Python script simulates checking for common typos in H-1B immigration documents (like I-797A or I-94). It compares an "expected" set of applicant data with "received" document data, identifies discrepancies in key fields such as name, date of birth, or visa category, and suggests potential correction actions, mirroring the article's focus on identifying and correcting errors.

## Language

`python`

## How to Run

Save the code as `main.py`. Open a terminal or command prompt, navigate to the directory where you saved the file, and run:
`python main.py`
